# Plantilla de marca

Copiar esta carpeta a `marcas/<nombre-de-la-marca>/` y completar con el usuario:

- `marca.md` — obligatorio: reglas visuales y datos verificados.
- `linkedin.md` — si la marca publica en LinkedIn (ver `marcas/asignar/linkedin.md` como ejemplo).
- `calendario.md` — pilares de contenido y fechas.
- `carruseles-aprobados.md` — se llena a medida que se aprueban.
- `personas.md` — quién pide y aprueba. **No se sube al repo** (está en `.gitignore`).
- `referentes/` — capturas de referentes externos. **No se suben al repo.**
